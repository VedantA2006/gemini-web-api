Authenticate Gemini Web

From your regular browser (Chrome, Edge, or Firefox) where you are already logged into gemini.google.com:

  1. Press F12 (DevTools) ➔ Application (or Storage) ➔ Cookies ➔ https://gemini.google.com
  2. Copy the value of __Secure-1PSID (or copy your full Cookie string).

Run either of these commands in your PowerShell or terminal in the project directory:

Option A: Interactive browser setup
.\.venv\Scripts\python.exe scripts/setup_browser.py
Option B: Direct cookie import in console
.\.venv\Scripts\python.exe scripts/import_cookies.py "__Secure-1PSID=YOUR_COOKIE"
